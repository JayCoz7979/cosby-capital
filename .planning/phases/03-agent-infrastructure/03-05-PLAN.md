# Plan 03-05: Agent 8 — capital-credit-coach

## Goal

Build and deploy the `capital-credit-coach` agent. This agent generates a personalized 6-step credit roadmap for every new paid client. The roadmap is educational — the client takes these steps themselves. Claude generates the roadmap with specific thresholds (580/600/625/650/700) and trade line recommendations. Fires on signup for all paid tiers.

## Context

- Schedule: On new client signup (all paid tiers: starter, growth, capital_partner, done_for_you)
- Trigger: `agent_trigger_queue` with trigger_type = 'signup'
- Output: `credit_roadmaps` record with `steps` (jsonb), `agent_summary` text
- Email: "Your credit roadmap is ready" — `requires_client_approval = false`
- Tone: Educational only — client acts themselves, Cosby Capital does not take action
- NOT credit repair (that's Agent 9, DFY only, requires CROA compliance + surety bond)

## Security Requirements

- S10-002: `sanitizeForPrompt()` on all client data
- S14-002: `scanOutputConfidentiality()` on all Claude output
- ABSOLUTE ZERO: Never mention loan rates, APR, or specific interest rates
- Disclaimer on every email: "These are educational recommendations. Cosby Capital does not take action on your behalf for credit repair. Please consult a licensed credit counselor for personalized advice."
- Zod validation on client data
- Check `subscription_status = 'active'` before running (skip free tier if applicable)

### Task 2: agents/capital-credit-coach/roadmap.js

```javascript
'use strict'
const { createMessage } = require('../lib/anthropic')
const { sanitizeForPrompt, scanOutputConfidentiality } = require('../lib/sanitize')
const { CircuitBreaker } = require('../lib/circuit-breaker')
const { sendAlert } = require('../lib/telegram')
const logger = require('../lib/logger')

const AGENT_NAME = 'capital-credit-coach'
const breaker = new CircuitBreaker({ threshold: 3, resetTimeoutMs: 120000 })

// Credit score thresholds that unlock lender tiers
const SCORE_THRESHOLDS = {
  580: 'Microloan lenders and CDFIs (SBA Microloans, Accion, LiftFund)',
  600: 'Online lenders (Fundbox, Credibly, Kabbage)',
  625: 'SBA-preferred lenders (OnDeck, Bluevine)',
  650: 'SBA 7(a) program eligibility',
  700: 'Traditional bank loans and best SBA terms',
}

async function generateCreditRoadmap(client) {
  const safeBusinessName = sanitizeForPrompt(client.business_name)
  const safeCreditRange = sanitizeForPrompt(client.credit_score_range || 'unknown')
  const safeIndustry = sanitizeForPrompt(client.industry || 'general business')
  const safeRevenue = sanitizeForPrompt(client.annual_revenue ? `$${client.annual_revenue.toLocaleString()}` : 'not provided')
  const safeYears = sanitizeForPrompt(client.years_in_business?.toString() || 'unknown')
  const safeDebt = sanitizeForPrompt(client.has_existing_debt ? `Yes, approximately $${client.existing_debt_amount?.toLocaleString() || 'unknown'}` : 'No existing debt')

  const thresholdList = Object.entries(SCORE_THRESHOLDS)
    .map(([score, unlocks]) => `- Score ${score}+: ${unlocks}`)
    .join('\n')

  const systemPrompt = `You are a business credit education specialist helping entrepreneurs understand how to build business credit.
Your advice is STRICTLY EDUCATIONAL. The client will take these steps themselves.
You are NOT providing credit repair services. You are NOT a licensed financial advisor.
RULES:
1. Never mention specific interest rates, APR, loan rates, or points
2. Never guarantee outcomes or approval chances
3. Never suggest disputing accurate information
4. Focus on credit-building actions: payment history, utilization, age of accounts, trade lines
5. Be specific, actionable, and encouraging
6. Reference the score thresholds provided — they are accurate for this platform's lender database`

  const userPrompt = `Business profile:
Business: ${safeBusinessName}
Current credit range: ${safeCreditRange}
Industry: ${safeIndustry}
Annual revenue: ${safeRevenue}
Years in business: ${safeYears}
Existing debt: ${safeDebt}

Lender unlock thresholds on this platform:
${thresholdList}

Generate a personalized 6-step credit improvement roadmap. For each step:
- Give a specific, actionable title
- Provide 2-3 sentences of guidance
- Include an estimated timeframe
- Note which lender tier they unlock when this step improves their score

Return as JSON:
{
  "current_score_context": "brief assessment of their current position",
  "target_score": 700,
  "estimated_timeline_months": <number>,
  "steps": [
    {
      "step": 1,
      "title": "...",
      "description": "...",
      "timeframe": "...",
      "milestone": "score improvement target or lender tier unlocked"
    }
  ],
  "quick_wins": ["action that could improve score in 30 days or less"]
}`

  const response = await breaker.call(() => createMessage({
    systemPrompt,
    userPrompt,
    maxTokens: 2048,
  }))

  const rawText = response.content[0]?.text || '{}'

  // Scan output (S14-002)
  const scan = scanOutputConfidentiality(rawText)
  if (!scan.safe) {
    await sendAlert(`🚨 capital-credit-coach: Loan terms detected in output — ABORTED\nFlags: ${JSON.stringify(scan.flags)}`, 'error').catch(() => {})
    logger.error(AGENT_NAME, 'CRITICAL: Loan terms in credit roadmap output', { flags: scan.flags })
    throw new Error('Credit roadmap output failed confidentiality scan')
  }

  try {
    const jsonMatch = rawText.match(/\{[\s\S]*\}/)
    return jsonMatch ? JSON.parse(jsonMatch[0]) : null
  } catch {
    logger.warn(AGENT_NAME, 'Failed to parse roadmap JSON', { raw: rawText.slice(0, 200) })
    return null
  }
}

module.exports = { generateCreditRoadmap, SCORE_THRESHOLDS }
```

### Task 3: agents/capital-credit-coach/index.js (main entry)

```javascript
'use strict'
require('dotenv').config()
const cron = require('node-cron')
const { z } = require('zod')
const { getServiceClient } = require('../lib/supabase')
const { logAndSend } = require('../lib/email')
const logger = require('../lib/logger')
const { generateCreditRoadmap, SCORE_THRESHOLDS } = require('./roadmap')

const AGENT_NAME = 'capital-credit-coach'

const PAID_TIERS = ['starter', 'growth', 'capital_partner', 'done_for_you']

const ClientSchema = z.object({
  id: z.string().uuid(),
  business_name: z.string().min(1),
  owner_name: z.string().min(1),
  email: z.string().email(),
  industry: z.string().nullable(),
  credit_score_range: z.string().nullable(),
  subscription_tier: z.string(),
  subscription_status: z.string(),
  onboarding_completed: z.boolean(),
  annual_revenue: z.number().nullable(),
  years_in_business: z.number().nullable(),
  has_existing_debt: z.boolean(),
  existing_debt_amount: z.number().nullable(),
})

async function runForClient(clientId, triggerType = 'signup') {
  const supabase = getServiceClient()
  const startMs = Date.now()

  const { data: rawClient, error: clientErr } = await supabase
    .from('clients').select('*').eq('id', clientId).single()

  if (clientErr || !rawClient) throw new Error(`Client ${clientId} not found`)

  const client = ClientSchema.parse(rawClient)

  // Credit coach runs for all paid tiers
  if (!PAID_TIERS.includes(client.subscription_tier) || client.subscription_status !== 'active') {
    logger.info(AGENT_NAME, 'Skipping — not a paid active client', { clientId, tier: client.subscription_tier })
    return
  }

  if (!client.onboarding_completed) {
    logger.info(AGENT_NAME, 'Skipping — onboarding not complete', { clientId })
    return
  }

  // Check if roadmap already exists (idempotent — don't overwrite existing roadmap)
  const { data: existingRoadmap } = await supabase
    .from('credit_roadmaps')
    .select('id, created_at')
    .eq('client_id', clientId)
    .order('created_at', { ascending: false })
    .limit(1)
    .single()
    .catch(() => ({ data: null }))

  if (existingRoadmap) {
    logger.info(AGENT_NAME, 'Roadmap already exists — skipping', { clientId, roadmapId: existingRoadmap.id })
    return
  }

  logger.info(AGENT_NAME, 'Generating credit roadmap', { clientId, triggerType })

  const roadmap = await generateCreditRoadmap(client)

  if (!roadmap) {
    logger.warn(AGENT_NAME, 'Roadmap generation returned null', { clientId })
    await supabase.from('agent_logs').insert({
      agent_name: AGENT_NAME,
      client_id: clientId,
      action: 'credit_roadmap_run',
      result: 'null_response',
      duration_ms: Date.now() - startMs,
    })
    return
  }

  // Save roadmap to DB
  const { data: savedRoadmap, error: saveErr } = await supabase
    .from('credit_roadmaps')
    .insert({
      client_id: clientId,
      current_score_range: client.credit_score_range,
      target_score: roadmap.target_score || 700,
      steps: roadmap.steps,
      agent_summary: roadmap.current_score_context,
      last_updated_by: AGENT_NAME,
    })
    .select()
    .single()

  if (saveErr) throw new Error(`Failed to save roadmap: ${saveErr.message}`)

  // Email the client
  const firstStep = roadmap.steps?.[0]
  const quickWins = roadmap.quick_wins || []

  const bodyHtml = `
<p>Hi ${client.owner_name},</p>
<p>Your personalized <strong>Business Credit Roadmap</strong> is ready in your Cosby Capital dashboard.</p>
<p>${roadmap.current_score_context || 'Based on your current credit profile, here\'s your path to stronger business credit.'}</p>
${firstStep ? `<p><strong>Your first step:</strong> ${firstStep.title} — ${firstStep.description}</p>` : ''}
${quickWins.length > 0 ? `<p><strong>Quick wins (30 days or less):</strong></p><ul>${quickWins.map((w) => `<li>${w}</li>`).join('')}</ul>` : ''}
<p>Your roadmap includes 6 steps with specific actions and the credit score thresholds that unlock new funding opportunities on your dashboard.</p>
<p><a href="https://cosbycapital.com/dashboard/credit" style="background:#0A1628;color:#C9A84C;padding:12px 24px;text-decoration:none;border-radius:4px;display:inline-block;margin:16px 0">View My Credit Roadmap →</a></p>
<p style="font-size:12px;color:#666;border-top:1px solid #eee;padding-top:16px;margin-top:24px">
  <em>These are educational recommendations. Cosby Capital does not take action on your behalf for credit repair.
  For credit repair services, consult a licensed credit counselor. Credit improvement timelines vary based on individual circumstances.
  This is not a guarantee of any specific outcome.</em>
</p>`

  await logAndSend(supabase, {
    agentName: AGENT_NAME,
    clientId: client.id,
    emailType: 'credit_roadmap_ready',
    toEmail: client.email,
    toName: client.owner_name,
    subject: 'Your Business Credit Roadmap is ready',
    bodyHtml,
    requiresClientApproval: false,
  })

  // Compliance log
  await supabase.from('compliance_log').insert({
    agent_name: AGENT_NAME,
    client_id: clientId,
    communication_type: 'credit_roadmap_email',
    recipient_email: client.email,
    subject: 'Credit roadmap ready',
    content_summary: `Sent educational credit roadmap — ${roadmap.steps?.length || 0} steps, ${roadmap.estimated_timeline_months || '?'} month timeline`,
    contained_loan_terms: false,
  }).catch((e) => logger.warn(AGENT_NAME, 'Compliance log failed', { error: e.message }))

  await supabase.from('agent_logs').insert({
    agent_name: AGENT_NAME,
    client_id: clientId,
    action: 'credit_roadmap_run',
    result: JSON.stringify({ roadmap_id: savedRoadmap.id, steps: roadmap.steps?.length, trigger: triggerType }),
    duration_ms: Date.now() - startMs,
  })

  logger.info(AGENT_NAME, 'Credit roadmap generated and sent', { clientId, roadmapId: savedRoadmap.id })
}

async function processTriggerQueue() {
  const supabase = getServiceClient()

  const { data: triggers } = await supabase
    .from('agent_trigger_queue')
    .select('*')
    .eq('agent_name', AGENT_NAME)
    .eq('status', 'pending')
    .order('created_at', { ascending: true })
    .limit(10)

  if (!triggers?.length) return

  for (const trigger of triggers) {
    try {
      await supabase.from('agent_trigger_queue').update({ status: 'processing' }).eq('id', trigger.id)
      await runForClient(trigger.client_id, trigger.trigger_type)
      await supabase.from('agent_trigger_queue').update({ status: 'done', processed_at: new Date().toISOString() }).eq('id', trigger.id)
    } catch (err) {
      logger.error(AGENT_NAME, 'Trigger queue error', { triggerId: trigger.id, error: err.message })
      const retries = (trigger.retry_count || 0) + 1
      await supabase.from('agent_trigger_queue').update({
        status: retries >= 3 ? 'failed' : 'pending',
        retry_count: retries,
        error: err.message,
      }).eq('id', trigger.id)
    }
  }
}

// Poll trigger queue every 5 minutes (signup-triggered)
cron.schedule('*/5 * * * *', processTriggerQueue)

processTriggerQueue().catch((e) => logger.error(AGENT_NAME, 'Startup trigger poll failed', { error: e.message }))

logger.info(AGENT_NAME, 'capital-credit-coach started', { schedule: 'trigger queue every 5min (signup-based)' })
```
