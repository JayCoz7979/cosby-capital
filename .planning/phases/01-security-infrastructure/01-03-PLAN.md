### Task 4: Create migration 002 — RLS policies
File: `supabase/migrations/20240101000002_rls_policies.sql`

Create RLS policies for all tables. Pattern:
- clients: `auth.uid() = user_id` for SELECT/INSERT/UPDATE/DELETE
- lenders, grants: public read, admin-only write
- grant_matches, lender_matches: client reads own data only
- agent_emails: client can SELECT (own), no INSERT/UPDATE/DELETE from client
- client_documents: client reads/uploads own, no cross-tenant access
- notifications: client reads own only
- admin_audit_log: service_role INSERT only, NO DELETE (S8-003)

Verify after: `SELECT tablename FROM pg_tables WHERE schemaname='public' AND tablename NOT IN (SELECT DISTINCT tablename FROM pg_policies);` must return zero rows.

### Task 5: Create migration 003 — security tables
File: `supabase/migrations/20240101000003_security_tables.sql`

Each table includes RLS in the same file (S11-012):

**trusted_devices** (device fingerprint login — TIER 1 item 002):
```sql
CREATE TABLE trusted_devices (
  id uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id uuid REFERENCES auth.users(id) ON DELETE CASCADE,
  device_hash text NOT NULL,
  device_name text,
  trusted_at timestamptz DEFAULT now(),
  last_seen_at timestamptz DEFAULT now(),
  expires_at timestamptz DEFAULT (now() + interval '90 days'),
  ip_address inet,
  user_agent text
);
ALTER TABLE trusted_devices ENABLE ROW LEVEL SECURITY;
CREATE POLICY "users_own_devices" ON trusted_devices FOR ALL USING (auth.uid() = user_id);
```

**processed_webhook_events** (Stripe idempotency — S6-001, S14-009):
```sql
CREATE TABLE processed_webhook_events (
  id uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  stripe_event_id text UNIQUE NOT NULL,
  event_type text NOT NULL,
  processed_at timestamptz DEFAULT now(),
  payload_hash text
);
ALTER TABLE processed_webhook_events ENABLE ROW LEVEL SECURITY;
-- Service role only — no client access
CREATE POLICY "service_role_only" ON processed_webhook_events FOR ALL USING (false);
```

**active_sessions** (concurrent session detection — GAP-256):

**deletion_requests** (CCPA — S9-010):
```sql
CREATE TABLE deletion_requests (
  id uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id uuid REFERENCES auth.users(id),
  email text NOT NULL,
  requested_at timestamptz DEFAULT now(),
  status text DEFAULT 'pending' CHECK (status IN ('pending', 'processing', 'completed', 'denied')),
  completed_at timestamptz,

ALTER TABLE deletion_requests ENABLE ROW LEVEL SECURITY;

```

**admin_audit_log** (immutable audit — S8-003):
```sql
CREATE TABLE admin_audit_log (
  id uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  actor_id uuid,
  actor_email text,
  action text NOT NULL,
  resource_type text,
  resource_id text,
  ip_address inet,
  user_agent text,
  metadata jsonb,
  created_at timestamptz DEFAULT now()
);
ALTER TABLE admin_audit_log ENABLE ROW LEVEL SECURITY;
-- INSERT only from service_role — no UPDATE/DELETE ever
CREATE POLICY "service_role_insert_only" ON admin_audit_log FOR INSERT WITH CHECK (true);
-- Trigger prevents UPDATE/DELETE
CREATE OR REPLACE FUNCTION prevent_audit_modification()
RETURNS TRIGGER AS $$
BEGIN
  RAISE EXCEPTION 'Audit log is immutable — modifications not allowed';
END;
$$ LANGUAGE plpgsql;
CREATE TRIGGER audit_log_immutable
  BEFORE UPDATE OR DELETE ON admin_audit_log
  FOR EACH ROW EXECUTE FUNCTION prevent_audit_modification();
```

### Task 6: Create migration 004 — extensions + security functions
File: `supabase/migrations/20240101000004_extensions_and_functions.sql`

```sql
-- Extensions
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS "pg_trgm";
CREATE EXTENSION IF NOT EXISTS "pgsodium";
CREATE EXTENSION IF NOT EXISTS "pg_cron";

-- REVOKE cron from authenticated role (GAP-216)
REVOKE ALL ON SCHEMA cron FROM authenticated;
REVOKE ALL ON ALL TABLES IN SCHEMA cron FROM authenticated;

-- Honeypot columns on grants/lenders (S8-005)
ALTER TABLE grants ADD COLUMN IF NOT EXISTS _t timestamptz DEFAULT now();
ALTER TABLE lenders ADD COLUMN IF NOT EXISTS _t timestamptz DEFAULT now();
ALTER TABLE grants ADD COLUMN IF NOT EXISTS _honeypot text DEFAULT NULL;
ALTER TABLE lenders ADD COLUMN IF NOT EXISTS _honeypot text DEFAULT NULL;

-- REVOKE DELETE on admin_audit_log at role level (belt and suspenders)

```
