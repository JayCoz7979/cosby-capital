# Plan 01-04: Shared Security Utilities + Middleware + App Shell

## Objective

Create the security utility layer that all features depend on, plus middleware and app shell.

## Context

- Reference: `phase1-build-sequence.md` Steps 1.7, 2.3
- Security requirements: S14-003 (logger with PCI scrubbing), S9-003 (sanitize prompts), S9-005 (scan output confidentiality), S8-011 (sanitizeForEmail), A01 (verifyOwnership), S16-004 (50ms minimum on verifyOwnership), A02 (JWT algorithm lock), A06 (requireTier), GAP-255 (max on all string fields), GAP-257 (central error handler), GAP-258/259 (validateRedirect), S13-008 (CORS allowlist), GAP-255 (Content-Length limit), S12-003 (no NODE_ENV bypasses)
- Brand: Navy #0A1628, Gold #C9A84C, Playfair Display + DM Sans

### Task 8: Create middleware.ts
Full route protection middleware.

Key behaviors:
- JWT verification via Supabase SSR on all `/dashboard/*`, `/api/*` (except webhook routes), `/admin/*`
- Admin IP allowlist: `/admin/*` routes return 404 (NOT 403) for non-allowlisted IPs
- Security headers on every response (reinforces next.config.js)
- Content-Length > 65536 → 413 on API routes (GAP-255)
- CORS allowlist for API routes (S13-008): only cosbycapital.com + localhost
- No NODE_ENV bypass conditions anywhere (S12-003)
- Stripe webhook route (`/api/webhooks/stripe`) excluded from auth matcher
- VAPI webhook route excluded from auth matcher

