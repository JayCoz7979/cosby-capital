# Plan 01-02: GitHub Security Workflows + CI/CD Files

## Objective

Create all GitHub Actions workflows and CI/CD files for security enforcement on every PR and push.

## Context

- Reference: `phase1-build-sequence.md` Step 1.3
- Reference: `.github/config-files-reference.txt` (already in project — contains templates for .gitleaks.toml and PR template)
- Security requirements: S7-009 (Snyk + Gitleaks + Semgrep), S13-001 (CodeQL), S10-010 (SBOM), S15-003 (trust-logic-check), S11-002 (version gate), S11-004 (Supabase Security Advisor), S12-009 (PR template)

## Tasks

### Task 1: Create .github/workflows/security.yml
Snyk + Gitleaks + Semgrep on all PRs. Blocks merge on any HIGH or CRITICAL finding.
```yaml
name: Security Scan
on:
  pull_request:
    branches: [main, develop]
  push:
    branches: [main]
jobs:
  gitleaks:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - uses: gitleaks/gitleaks-action@v2
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
  semgrep:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: returntocorp/semgrep-action@v1
        with:
          config: >-
            p/javascript
            p/nodejs
            p/nextjs
            p/owasp-top-ten
  snyk:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - run: npm ci --ignore-scripts
      - uses: snyk/actions/node@master
        env:
          SNYK_TOKEN: ${{ secrets.SNYK_TOKEN }}
        with:
          args: --severity-threshold=high
```

### Task 5: Create .github/workflows/trust-logic-check.yml
Block PRs containing eval/exec/new Function (S15-003, S16-001).
```yaml
name: Trust Logic Check
on: [pull_request]
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Check for dangerous patterns
        run: |
          if grep -rn "eval(\|exec(\|new Function(" src/ agents/ lib/ app/ 2>/dev/null | grep -v "node_modules\|\.test\.\|\.spec\."; then
            echo "BLOCKED: eval/exec/new Function detected in source code (S16-001)"
            exit 1
          fi
          if grep -rn "SYSTEM:" .github/; then
            echo "BLOCKED: 'SYSTEM:' found in PR body context (GAP-221)"
            exit 1
          fi
```

### Task 6: Create .github/workflows/nextjs-version-gate.yml
Block deploy if Next.js < 15.5.18 (S11-002).
```yaml
name: Next.js Version Gate
on: [push, pull_request]
jobs:
  version-check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Verify Next.js version
        run: |
          NEXT_VERSION=$(node -e "const p = require('./package.json'); console.log(p.dependencies.next || p.devDependencies.next)")
          MIN_VERSION="15.5.18"
          if [ "$(printf '%s\n' "$MIN_VERSION" "$NEXT_VERSION" | sort -V | head -n1)" != "$MIN_VERSION" ]; then
            echo "BLOCKED: Next.js $NEXT_VERSION is below minimum required $MIN_VERSION (CVE patch)"
            exit 1
          fi
          echo "✓ Next.js $NEXT_VERSION >= $MIN_VERSION"
```

```yaml
      - "dependencies"

```
