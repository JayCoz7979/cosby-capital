## Layout Structure

The dashboard uses a two-column shell: persistent left sidebar + main content area.

```
┌────────────────────────────────────────────────┐
│  Top Nav (64px) — logo · notifications · avatar │
├──────────────┬─────────────────────────────────┤
│  Sidebar     │  Main Content Area              │
│  240px       │  flex-1, min-w-0                │
│  bg-forest   │  bg-gray-50                     │
│  (hidden on  │  px-6 py-8 (md: px-8)          │
│   mobile,    │                                 │
│   drawer)    │                                 │
└──────────────┴─────────────────────────────────┘
```

- Background dominant surface: `bg-gray-50` (#F9FAFB) for main content area
- Sidebar background: `#2D5016` (forest green) — brand primary; note: `tailwind.config.ts` currently defines a navy token that must be replaced with forest green during Phase 4 execution
- Top nav background: `#2D5016` (forest green) with bottom border `border-white/10`
- Cards float on the gray-50 surface as white panels

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F9FAFB` (gray-50) | Main content area background, page background |
| Secondary (30%) | `#2D5016` (forest green) | Sidebar, top nav, card top-border accent, primary button background |
| Surface (cards) | `#FFFFFF` (white) | All card backgrounds, modal backgrounds, dropdown backgrounds |
| Accent (10%) | `#C9A84C` (gold) | Reserved elements only — see list below |
| Destructive | `#DC2626` (red-600) | Document delete confirmation, form error text, error toasts |

Accent (`#C9A84C`) reserved for:

1. Funding Readiness Score ring/fill indicator
2. Grant match score badge fill
3. Active sidebar navigation item indicator (left border + text)
4. Notification dot (unread indicator)
5. Primary CTA button text color (on forest green background, Button variant="primary" background updated to #2D5016)
6. Progress bar fill (extends OnboardingProgressBar pattern)
7. "New" or "High Priority" status chip on grant/lender cards

Accent is NOT used for: secondary buttons, ghost buttons, input focus rings on dark backgrounds, table row hover, general link text.

Source: brand spec (Forest/Hunter Green #2D5016 as primary, Gold #C9A84C accent, White/Off-white surfaces, Charcoal text). `tailwind.config.ts` currently defines a navy token — this must be updated to forest green in the DashboardShell plan.

## Interaction Contracts

### Grant Match List

- Default sort: score descending
- Filter chips: All / Grants / SBIR / State / Federal / Private
- Search: client-side filter on grant name and description fields
- Score badge: gold fill at 80%+, amber at 50-79%, gray below 50%
- Match reasons: collapsed by default, expandable on "View Match Details"
- Pagination: 10 items per page, simple prev/next

### Lender Introduction Request

- Button state machine: idle → loading (spinner) → success (pill changes to "Pending Review") → error (toast)
- One active request per lender enforced client-side (button disabled if request already exists)
- FTC disclosure rendered as static text below each lender card — never hidden

### Document Upload

- Accepted MIME types communicated before drag-and-drop: PDF, DOCX, XLSX, PNG, JPG
- Max size: 10 MB (shown as hint text below uploader)
- Upload state: idle → uploading (progress bar, gold fill) → scanning (spinner + "Scanning for threats…") → complete (green checkmark + file row appears) → error (red message)
- Signed URL download: clicking "Download File" calls server-side API route — no direct Supabase Storage URL in browser
- Ownership verification enforced server-side (verifyOwnership() with 50ms minimum delay per STATE.md decisions)

### Realtime Notifications

- Supabase Realtime channel subscribed on mount with `client_id` filter
- Unread count shown as gold dot on bell icon in TopNav
- Feed auto-scrolls to newest on arrival
- Reconnection state shown as non-blocking inline banner ("Live updates paused. Reconnecting…")
- No push notification permission requested in Phase 4

### Funding Readiness Score

- Rendered on dashboard home as the first visible element (above the fold)
- Score range: 0–100
- Visual: arc progress (`@radix-ui/react-progress` or SVG arc) with gold fill
- Label below score: tier description (e.g. "Strong — Ready to Apply")
- Score breakdowns (up to 5 factors) shown as compact labeled rows below arc
- No interactivity — display only

## Accessibility Baseline

All interactive elements must meet WCAG 2.1 AA:

- Focus ring: `ring-2 ring-[#C9A84C] ring-offset-2` on all interactive elements (matches existing Input pattern)
- `aria-label` required on icon-only buttons (notification bell, close buttons, sort arrows)
- `role="status"` on loading indicators and reconnection banner
- `role="alert"` on error messages (matches existing Input error pattern)
- Destructive ConfirmDialog: focus trapped, ESC closes, confirm button NOT auto-focused (prevent accidental activation)
- ApprovalStatusPill: communicate status via text, not color alone (label always present)
- Documents table: `scope="col"` on all column headers
