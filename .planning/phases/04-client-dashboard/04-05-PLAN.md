  <action>
    src/app/api/dashboard/approvals/route.ts:
    Export GET and PATCH handlers.

    GET handler:
    - Auth: createServerClient() → getSession() → 401 if missing
    - Resolve client: .from('clients').select('id, subscription_tier').eq('user_id', userId).maybeSingle() → 404 if null
    - Import canViewApprovals from '@/lib/feature-gates'; if !canViewApprovals(client.subscription_tier) → 403 { error: 'Upgrade to Growth tier to view approvals' }
    - Query: serviceClient.from('agent_emails').select('id, agent_name, email_type, to_name, to_email, subject, body_html, created_at, client_approved, requires_admin_approval').eq('client_id', client.id).eq('requires_client_approval', true).eq('client_approved', false).order('created_at', { ascending: false })
    - Return 200 { approvals: data }

    PATCH handler:
    - Auth: same pattern → 401 if missing
    - Resolve client (same as GET)
    - Parse body: const { id, action } = await req.json()
    - Validate: id must be a non-empty string; action must be 'approve' or 'reject'
    - If invalid → 400 { error: 'id and action (approve|reject) are required' }
    - Verify ownership: serviceClient.from('agent_emails').select('id').eq('id', id).eq('client_id', client.id).maybeSingle() → if null → 404 { error: 'Approval not found' }
    - Update: if action === 'approve':
        .from('agent_emails').update({ client_approved: true, client_approved_at: new Date().toISOString() }).eq('id', id)
      if action === 'reject':
        .from('agent_emails').update({ client_approved: false, client_approved_at: new Date().toISOString() }).eq('id', id)
        NOTE: For reject, we set client_approved=false + client_approved_at to record the rejection time. Admin agents check client_approved=true before sending — rejected items stay unsent.
    - Return 200 { id, action, updated: true }
    - Wrap in try/catch; log errors with logger from '@/lib/logger'

    src/app/api/dashboard/credit/route.ts:
    Export GET handler.
    - Auth: createServerClient() → getSession() → 401 if missing
    - Resolve client: .from('clients').select('id, subscription_tier, credit_score_range').eq('user_id', userId).maybeSingle() → 404 if null
    - Query: serviceClient.from('credit_roadmaps').select('id, current_score_range, target_score, target_date, steps, agent_summary, updated_at').eq('client_id', client.id).order('created_at', { ascending: false }).limit(1).maybeSingle()
    - Return 200 { roadmap: data | null, credit_score_range: client.credit_score_range }
      If no roadmap: { roadmap: null, credit_score_range: client.credit_score_range }
  </action>
