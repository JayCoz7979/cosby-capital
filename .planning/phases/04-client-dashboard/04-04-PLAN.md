| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04-01 | Tampering | upload route MIME validation | mitigate | Server-side MIME type check against allowlist; file extension secondary check; Content-Type header not trusted alone (ASVS 12.2) |
| T-04-04-02 | Denial of Service | upload route file size | mitigate | 10MB limit enforced server-side before storage upload; 400 returned immediately |
| T-04-04-03 | IDOR | download/delete ownership | mitigate | Custom ownership check with 50ms minimum delay (replicating verifyOwnership S16-004 pattern); 404 on failure (not 403) to prevent enumeration |
| T-04-04-04 | Information Disclosure | download route URL | mitigate | Returns signed URL with 3600s expiry only; raw Supabase Storage path never sent to browser; signed URL generated server-side only |
| T-04-04-05 | Elevation of Privilege | document upload feature gate | mitigate | canUploadDocuments() checked server-side in upload route; frontend disable is UX only |
</threat_model>
