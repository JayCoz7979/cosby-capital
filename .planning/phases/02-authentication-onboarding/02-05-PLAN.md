# Plan 02-05: Stripe Billing — 4 Tiers, Webhook Handler, Customer Portal

## Objective

Wire up complete Stripe payment infrastructure: secure Stripe server client (restricted key), checkout session creation for all 8 price points (4 tiers × monthly + annual), production-grade webhook handler with atomic idempotency (duplicate event prevention), customer portal for subscription management, and subscription tier enforcement on all gated routes.

### Task 1: Create Stripe tables migration
Create `supabase/migrations/20240101000009_stripe_tables.sql`:

```sql
-- Store Stripe subscription state
ALTER TABLE clients ADD COLUMN IF NOT EXISTS stripe_customer_id text;
ALTER TABLE clients ADD COLUMN IF NOT EXISTS stripe_subscription_id text;
ALTER TABLE clients ADD COLUMN IF NOT EXISTS subscription_current_period_end timestamptz;
ALTER TABLE clients ADD COLUMN IF NOT EXISTS subscription_cancel_at_period_end boolean default false;

-- Fee invoices (for success fees, not subscriptions)
CREATE TABLE IF NOT EXISTS fee_invoices (
  id uuid primary key default uuid_generate_v4(),
  created_at timestamptz default now(),
  client_id uuid references clients(id) not null,
  amount_cents integer not null check (amount_cents > 0),
  description text not null,
  stripe_payment_link text,
  stripe_payment_intent_id text,
  paid boolean default false,
  paid_at timestamptz,
  dunning_count integer default 0,
  next_dunning_at timestamptz
);
ALTER TABLE fee_invoices ENABLE ROW LEVEL SECURITY;
CREATE POLICY "fee_own_read" ON fee_invoices FOR SELECT
  USING (client_id IN (SELECT id FROM clients WHERE user_id = auth.uid()));
CREATE POLICY "fee_service_write" ON fee_invoices FOR ALL
  USING (auth.role() = 'service_role');
```

### Task 3: Create create-checkout route
Create `src/app/api/stripe/create-checkout/route.ts` (POST):
- Auth required
- Input (Zod):
  ```typescript
  {
    tier: 'starter' | 'growth' | 'capital_partner',
    billing_period: 'monthly' | 'annual'
  }
  ```
- Validate tier + billing_period are valid combination
- Get or create Stripe customer:
  - Check `clients.stripe_customer_id` — if exists, use it
  - If not: `stripe.customers.create({ email, metadata: { client_id, user_id } })`
  - Update `clients.stripe_customer_id`
- Resolve price_id from `PRICE_IDS[tier_billing_period]`
- If price_id is empty/undefined: return 500 (env var not configured)
- Create Stripe Checkout Session:
  ```typescript
  stripe.checkout.sessions.create({
    customer: stripe_customer_id,
    mode: 'subscription',
    line_items: [{ price: price_id, quantity: 1 }],
    success_url: `${process.env.NEXT_PUBLIC_SITE_URL}/onboarding/step-6?success=true&session_id={CHECKOUT_SESSION_ID}`,
    cancel_url: `${process.env.NEXT_PUBLIC_SITE_URL}/onboarding/step-6?canceled=true`,
    subscription_data: {
      metadata: { client_id, user_id, tier, billing_period }
    },
    allow_promotion_codes: true,
    billing_address_collection: 'required',
  })
  ```
- Return `{ url: session.url }` — client redirects to this URL
- Log with sanitizeForLog() — no card data, no secret keys in logs

### Task 4: Create Stripe webhook handler
Create `src/app/api/webhooks/stripe/route.ts`:

**CRITICAL: This route must NOT have JWT auth middleware applied.** Verify `middleware.ts` matcher excludes `/api/webhooks/stripe` (it should from Phase 1).

- Accept raw body (required for signature verification)
- Configure Next.js to not parse body: export `config = { api: { bodyParser: false } }` (or use `request.text()`)
- **FIRST STEP: verify webhook signature**:
  ```typescript
  const sig = request.headers.get('stripe-signature')!
  const event = stripe.webhooks.constructEvent(
    rawBody,
    sig,
    process.env.STRIPE_WEBHOOK_SECRET!
  )
  ```
  If verification fails: return 400 (do not process)

- **Idempotency check BEFORE processing**:
  ```typescript
  const existing = await supabase
    .from('processed_webhook_events')
    .select('id')
    .eq('stripe_event_id', event.id)
    .single()
  if (existing.data) return Response.json({ received: true }) // already processed
  ```

- **Allowlisted event types only** — ignore everything else:
  - `checkout.session.completed`
  - `customer.subscription.updated`
  - `customer.subscription.deleted`
  - `invoice.payment_failed`
  - `invoice.paid`

- **Process each event**:

  `checkout.session.completed`:
  - Get `client_id` from `session.subscription_data.metadata.client_id`
  - Get tier from `subscription.items.data[0].price.id` → `getTierFromPriceId()`
  - Update `clients`: `{ subscription_tier: tier, subscription_status: 'active', stripe_subscription_id: subscription.id, subscription_current_period_end }`
  - Telegram: "💰 New subscriber: [business_name] — [tier] [billing_period]"

  `customer.subscription.updated`:
  - Update `clients.subscription_tier`, `subscription_status`, `subscription_current_period_end`, `subscription_cancel_at_period_end`

  `customer.subscription.deleted`:
  - Update `clients.subscription_status = 'canceled'`, `subscription_tier = null`

  `invoice.payment_failed`:
  - Update `clients.subscription_status = 'past_due'`
  - Telegram: "⚠️ Payment failed: [business_name] — invoice [invoice.id]"
  - Trigger dunning (insert to `agent_queue` for Agent 16 if infrastructure ready)

  `invoice.paid`:
  - Update `clients.subscription_status = 'active'` (clears past_due)

- **Atomic upsert to processed_webhook_events AFTER processing**:
  ```typescript
  await supabase.from('processed_webhook_events').upsert({
    stripe_event_id: event.id,
    event_type: event.type,
    processed_at: new Date().toISOString()
  }, { onConflict: 'stripe_event_id' })
  ```

- Return `Response.json({ received: true })` with status 200
- Log all events with sanitizeForLog() — **no raw body logged anywhere** (PCI requirement)
